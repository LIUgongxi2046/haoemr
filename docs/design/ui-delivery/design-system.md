# HaoEMR UI 设计系统 v1.0

> 视觉方向：A“临床可信蓝”。状态：`APPROVED_FOR_DESIGN`。本文与 `tokens.json` 共同构成 194 个页面的唯一视觉契约。

## 1. 品牌与感受

- 专业、稳定、可追溯；临床任务优先于装饰。
- 主色 `#1769E0`，深色导航 `#102A43`，成功 `#168C64`，警告 `#B7791F`，阻断 `#C53030`，AI 草稿 `#6D45C2`。
- 白色内容面、浅灰页面底、1px 边框、最小阴影；不使用玻璃拟态、大面积渐变或营销式插画。
- 顶栏使用可配置的品牌图形槽位 + `haoemr` 字标组件，不绑定医院品牌；导航、AI、录音和安全语义统一引用本地功能图标库，不使用 Emoji 或文字符号冒充最终图标。
- 专科总览和设备安全降级场景使用实际生成的 PNG 栅格资产，只做场景说明，不生成或暗示患者事实；来源见 `image-generation-manifest.csv`。

## 2. 字体与数字

- 中文：`PingFang SC`, `Microsoft YaHei`, system-ui；英文/Latin：`Inter`, `Segoe UI`, system-ui。
- 页标题 22/30 700，区块标题 14/22 700，正文 14/22 400，表格 13/20 400，辅助 12/18 400。不使用小于 12px 的临床正文。
- 病案号、住院号、床号、时间、剂量和生命体征使用等宽数字，防止列对齐漂移。

## 3. 壳层与栅格

- 顶栏 58px，一级导航 220px，业务域横向导航 48px；全局仅一个一级活动项。
- 工作站页使用 12–16px 密度，管理页使用 16–24px。标准间距为 4/8/12/16/24/32px。
- 三栏仅用于“列表—主任务—安全辅助”；病历正文最大 920px，来源与质控改为可收起抽屉或独立页，不长期挤压正文。
- 断点：1024/1280/1600/1920。200% 缩放允许降为单列，但保存、签署、返回和阻断原因必须可达。

## 4. 密度模式

| 模式 | 使用区域 | 控件高度 | 表格行 | 最小点击区 |
|---|---|---:|---:|---:|
| Compact | 门急住、病历、医技、专科 | 32px | 36px | 32px |
| Standard | 质控、数据、配置、管理 | 36px | 40px | 36px |
| Touch | 床旁、移动查房、扫码执行 | 48px | 52px | 44px |

密度只改变空间，不删除字段、权限、状态或安全拦截。

## 5. 医疗语义

| 语义 | 主色 | 图形/文字 | 行为 |
|---|---|---|---|
| 硬阻断 | `#C53030` | 八边形停止图标 + “阻断” + 左实线 | 不自动消失，展示来源、解除条件和责任人 |
| 危急 | `#B4232F` | 铃/放射状图标 + “危急” | 需确认接收、处置时间和闭环 |
| 警告 | `#B7791F` | 三角图标 + 后果文本 | 允许继续时记录理由 |
| 成功 | `#168C64` | 勾选 + 对象/时间 | 只表示业务已完成 |
| 信息 | `#1769E0` | 信息圆标 | 来源、说明和普通任务 |
| AI 草稿 | `#6D45C2` | AI 星形 + “待确认” | 显示 Agent/Skill/模型/来源，未确认不写入事实 |
| 过期/离线 | `#526275` | 时钟/断链 + 数据时间 | 不得静默展示旧数据 |

## 6. 核心组件契约

### 患者身份条

姓名+第二标识、当前就诊、科室/病区/床位、责任人、严重过敏/隔离/病危不可折叠掉。切换患者或就诊前检查草稿、录音和未完成高风险动作。

### 病历编辑器

- 分为文书目录、正文纸张、来源/质控抽屉；不使用固定三列宽面板。
- 自动保存明示“保存中/已保存/失败/冲突”；已签内容只读，更正必须新建版本、展示差异与传播范围。
- 临床事实、引用来源、规则命中、AI 建议使用不同容器与标记。

### 表单、列表、对话框

- 标签不依赖 placeholder；单位、来源、时间、版本和必填标识可见。
- 表头可固定，患者身份、时限、风险不随横滚离屏。
- 高风险动作使用独立审查页或宽抽屉，展示具体患者、对象、变化、后果、批准范围、恢复方式和审计。

### AI医助小南

- 顶栏与右下角全局可达，不遮挡保存、签署、确认和返回。
- 面板顶部始终显示患者/就诊/任务上下文；无患者时显示“无临床上下文”。
- Tool 动作必须回到原业务状态机逐次批准，拒绝、撤销、超时和回人工均有可见结果。

## 7. 交互状态

所有交互组件覆盖 default/hover/focus-visible/pressed/disabled/loading/success/error。页面族覆盖初始、加载、空、部分数据、过期、慢网、离线、超时、重连、无权限、会话过期、冲突、阻断、成功和恢复。专科另覆盖设备离线、身份/侧别/部位/牙位冲突、剂量异常、特殊隐私、母婴/夫妇关系异常。

## 8. 可访问性与医疗安全

- 正文对比度目标 ≥4.5:1，大字与非文本控件 ≥3:1；颜色不是唯一编码。
- `focus-visible` 使用 2px 蓝色外环 + 2px 偏移，键盘顺序与视觉顺序一致。
- 遵循 `prefers-reduced-motion`；不使用闪烁、大面积视差和无法暂停的自动轮播。
- 截图/打印需要受控脱敏；断网、缓存、旧数据和模拟数据不得静默呈现。
