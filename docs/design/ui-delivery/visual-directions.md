# HaoEMR 医疗 UI 视觉方向提案

## 共同不可变基线

- 患者身份、当前就诊、过敏/隔离/病危状态始终可见。
- 临床事实、人工草稿、AI 草稿、规则阻断和 AI 建议使用不同语义。
- 红色只表达危急、错误和硬阻断；不用于普通品牌强调。
- 所有主操作有键盘焦点、禁用、加载、成功与失败状态；200% 缩放不丢失操作。
- 临床页采用 8px 栅格和高密度模式；系统管理可使用标准密度；不使用大面积渐变或装饰插画干扰诊疗。

## A. 临床可信蓝（推荐）

| 字段 | 内容 |
|---|---|
| 关键词 | 稳定、可信、克制、高密度、全院统一 |
| 用户感受 | 接近成熟大型医院工作站，但层级更现代、病历写作更聚焦 |
| 色彩 | 主色 `#1769E0`；深导航 `#102A43`；青绿成功 `#168C64`；琥珀警告 `#B7791F`；红色阻断 `#C53030` |
| 材质 | 白/浅灰平面、1px 冷灰描边、极浅阴影；患者条与高风险使用实色边框 |
| 字体 | 中文系统无衬线；数值使用等宽数字；病历正文 14–16px、行高 1.65 |
| 图标 | 统一 1.75px 圆角线性图标；危急/阻断同时带形状与文字 |
| 适用 | 门急住、病历、医技、专科、质量、配置和系统管理均稳定 |
| 风险 | 若所有模块只用蓝色会缺少领域辨识；通过二级语义色和图标解决，不给每个科室随意换主题 |

## B. 温和医疗青

| 字段 | 内容 |
|---|---|
| 关键词 | 亲和、低疲劳、轻量、基层友好、自然 |
| 用户感受 | 更像现代门诊与基层协同平台，长时间使用柔和 |
| 色彩 | 主色 `#087F8C`；深青 `#164E63`；辅助蓝 `#2563EB`；风险色保持独立 |
| 材质 | 暖白背景、浅青分区、较软圆角和少量层叠卡片 |
| 字体 | 系统无衬线，标题稍大，列表行距略宽 |
| 图标 | 线性圆角图标；空状态可使用抽象医疗几何插画 |
| 适用 | 诊所、基层、门诊、随访、患者教育体验良好 |
| 风险 | 大型三级医院高密度病区可能显得松散；需强制 compact 模式并减少卡片化 |

## C. 中性专业灰 + 功能色

| 字段 | 内容 |
|---|---|
| 关键词 | 数据优先、极简、严肃、可定制、科研感 |
| 用户感受 | 类似高端专业工具，内容和状态比品牌更突出 |
| 色彩 | 中性墨灰 `#243B53`；主操作靛蓝 `#4055C8`；各业务只用受控语义色 |
| 材质 | 几乎无阴影、紧凑分割线、标签和表格为主 |
| 字体 | 数字/代码强调等宽；中文层级克制 |
| 图标 | 几何线性图标、较少装饰 |
| 适用 | 病历中心、数据中心、科研、管理后台和多院区白标部署 |
| 风险 | 对基层新用户不够亲和，患者/临床关键操作需要更强引导 |

## 建议

推荐选择 **A：临床可信蓝**。它与中国医院成熟工作站的认知负担最低，同时可以用更清晰的患者上下文、病历证据、AI 分层和专科工作流建立 haoemr 的产品辨识度。B 更适合后续患者端/基层轻量端，C 可作为管理员或科研密度变体，但不建议成为全产品唯一母版。
