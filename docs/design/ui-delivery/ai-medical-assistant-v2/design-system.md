# AI 医助小南 v2 设计系统增量

> 基线：[haoemr UI 设计系统 v1.0](../design-system.md) 与 [全局 Token](../tokens.json)。本文件只定义小南 v2 的增量契约；冲突时以患者安全、PRD 和全局设计系统为先。

## 1. 视觉方向

沿用 A「临床可信蓝」：专业、稳定、低装饰、来源可追溯。小南 IP 只承担入口识别、空状态和引导，不作为临床结论背书，也不在高风险阻断、危急值或审批页中使用拟人化表情淡化风险。

| 用途 | 表达 |
|---|---|
| 平台动作 | 品牌蓝 `#1769E0` |
| AI 候选 | 紫 `#6D45C2`，必须同时写“候选/待确认” |
| 就诊摘要 | 蓝 + 文档图标 + 文本 |
| 文书草拟 | 紫 + 羽笔图标 + 文本 |
| 病历质控 | 琥珀 + 盾牌图标 + 文本；硬阻断仍为红 |
| 结果闭环 | 青 + 闭环图标 + 文本 |
| 诊疗协同 | 绿 + 协作图标 + 文本 |

禁止为每个子 Agent 生成独立 IP、渐变或品牌色；子 Agent 继承主 Agent 语义，通过功能图标、中文角色名、状态、贡献和关键性区分。

## 2. 布局 Token

| Token | 值 | 用途 |
|---|---:|---|
| `assistant.launcher.minTarget` | 44px | 顶栏入口点击区 |
| `assistant.sidePanel.width` | 420px | 标准桌面 Dock |
| `assistant.sidePanel.widthWide` | 480px | ≥1600px |
| `assistant.drawer.width` | min(720px, 92vw) | 1024–1279px |
| `assistant.workspace.rail` | 360px | 执行计划右轨 |
| `assistant.workspace.contentMax` | 1180px | 结构化候选可读区 |
| `assistant.taskStrip.maxActions` | 3 | 本环节主要任务数 |

完整工作台使用 12 列：主任务 8 列、执行计划 4 列。窄于 1024px 或 200% 缩放时改为单列，执行计划置于候选之前。

## 3. 组件

### 3.1 `XiaonanLauncher`

- 图标 24–28px，文字“AI 医助小南”，数字徽标最大 `9+`。
- default/hover/focus-visible/pressed/unread/disabled/loading 全状态。
- `aria-expanded`、当前上下文变化与焦点归还必须实现。
- 无患者时不显示患者相关提醒数量。

### 3.2 `StageAssistStrip`

- 高 64–88px，蓝色 1px 边框，不使用大面积紫底。
- 标题“本环节可协助”，任务按钮最多 3 个。
- 每个任务按钮包含统一线性图标、动宾短语和可选一行说明。
- `hover` 展示结果类型；`disabled` 必须给出不可用原因。

### 3.3 `RoutePreviewCard`

固定四区：任务、主 Agent 与理由、数据范围、执行计划。底部动作顺序：取消 / 更换任务 / 开始生成。若需要澄清，替换为单一问题和 2–4 个业务选项，不展示自由 Agent 列表。

### 3.4 `TaskPlan`

- 每步最小高 56px；状态图标 20px；步骤标题 14/22 600。
- 状态：complete、running、pending、skipped、failed、blocked。
- running 可显示耗时，不显示虚假精确百分比。
- critical 失败显示“关键步骤”文字；不能只用红色。

### 3.5 `CandidateHeader`

展示候选类型、完整性、主 Agent、来源覆盖、未决项、生成时间、失效条件。`partial` 使用琥珀左轨和“部分完成”；ready 使用紫色候选标签，不使用绿色成功。

### 3.6 `SourceChip` / `SourceDrawer`

Chip 显示来源类型 + 日期/版本；默认最多 5 个，剩余进入“全部来源”。抽屉内必须包含定位、授权状态、取数时间和更正状态。无权来源不泄露对象标题。

### 3.7 `AgentTechnicalDetails`

默认折叠。使用 Definition List，不使用面向临床的彩色 Agent 卡片矩阵。版本、run ID、Tool code 使用等宽字体；秘密、Prompt、隐藏思维链和原始 PHI 不显示。

### 3.8 `ManualHandoff`

按钮文案统一为“转人工”；触发后显示已完成范围、当前草稿是否保留和人工入口。高风险情况下“转人工”与“停止任务”并列，停止使用红色描边而非实心危险按钮。

### 3.9 `ChildAgentCollaborationRail`

- 顶部固定主 Agent Leader Card，明确“任务负责人/负责最终候选”。
- 子 Agent 使用功能图标而非人物头像；卡片包含中文角色、归属、状态、当前动作、输入范围、贡献和查看入口。
- 串行接力用连接线 + “事实包已交接”等文本；并行协作者使用同组布局。
- 独立 Verification Card 必须标注“非子 Agent”，不计入子 Agent 人数。
- 完整规则见 `child-agent-experience.md`。

### 3.10 `ContributionBadge`

- 高 28px，最大一行，格式为“角色名 · 贡献类型 · 来源/发现数量”。
- 默认使用主 Agent 的浅色语义面，状态仍由独立状态图标和文字表达。
- 点击打开贡献抽屉，不把原始 Tool payload 或隐藏思维链暴露给用户。

## 4. 内容密度与层级

- 页面标题 22/30；任务标题 20/28；区块 14/22；正文 14/22；辅助 12/18。
- 临床正文和 AI 候选正文不小于 13px。
- 主任务页间距 16/24；侧面板 12/16；步骤内间距 8/12。
- 候选正文单行建议 50–80 个中文字符；最大可读宽 920px。
- 长 Agent/Skill/Tool code 只出现在技术详情，允许单词内换行和复制。

## 5. 状态视觉

| 状态 | 容器 | 主文案 | 主动作 |
|---|---|---|---|
| 安全空上下文 | 蓝灰信息面 | 当前未选择患者或任务 | 选择患者或任务 |
| 匹配中 | 蓝色信息面 + 静态/低动 loading | 正在匹配合适的任务方案 | 取消匹配 |
| 执行中 | 白面 + 蓝色 active step | 正在执行第 N 步 | 停止任务 / 转人工 |
| 部分完成 | 琥珀左轨 | 已完成范围 / 缺失范围 | 查看缺失原因 |
| 已阻断 | 红色左轨 | 阻断原因 / 解除条件 | 重新授权 / 返回人工流程 |
| 等待审阅 | 紫色候选标签 | 候选已生成，等待人工审阅 | 查看来源 / 对比 / 复制 |
| 子 Agent 接力 | 主 Agent 浅色语义面 + 接力文本 | 事实包已交给下一位协作者 | 查看贡献 |
| 对账中 | 蓝灰时钟 | 结果未知，正在核验真实状态 | 返回人工流程 |

`PARTIAL`、`BLOCKED`、`FAILED`、`EXPIRED` 的图标、标题和动作不同；不能复用一个通用错误 Toast。

## 6. IP 与图片规则

- Master：`assets/master/xiaonan-source-orchestration.png`。
- 角色固定：年轻男性、深蓝短发、白大褂、藏蓝衬衫、听诊器、蓝青边光、温和但不过度娱乐化。
- 允许：顶栏小头像、空状态、首次任务引导、来源/编排说明。
- 禁止：危急值、阻断、高风险审批、错误责任归属、实际完成/签署证明。
- 本次 Master 为浅蓝灰实体背景 PNG，`transparency=false`；使用时应作为完整方形插画槽位，不做抠图叠放或拉伸。

## 7. 动效

- 面板进入 160ms，透明度 + 8px 位移；reduced motion 为 0ms。
- active step 可使用低频 1.5s 描边呼吸，但不闪烁；reduced motion 改静态环。
- 运行状态只在服务端事件到达时更新，不用前端伪进度。
- 阻断、患者切换、审批过期立即切换，无平滑过渡延迟。

## 8. 可访问性

- 正文 ≥4.5:1，非文本边界与状态图标 ≥3:1。
- 所有状态含图标和文本；焦点环沿用全局 `2px + 2px offset`。
- Dock、Drawer、Workspace 的键盘顺序与视觉顺序一致；关闭返回发起按钮。
- `aria-live=polite` 用于普通进度，`assertive` 仅用于患者上下文失效或关键阻断。
- 执行计划对屏幕阅读器朗读“步骤 2/5，运行中，汇总近 24 小时变化”。
- 子 Agent 卡片朗读“查房记录草拟员，步骤 2/2，协作中，正在将事实包整理为查房记录”。
- 200% 缩放不固定底栏；候选、停止、转人工和来源仍可达。

## 9. 图标

标准功能图标复用项目统一图标库，保持 1.75–2px 线宽和圆端点。不得使用 Emoji、汉字圆标或模型生成图标作为最终功能图标。主 Agent 图标须同时有文本标签。
