# 状态与恢复矩阵

v0.2 将以下状态应用于原宿主页面与管理弹窗。旧全局状态工具栏已移除；本轮原型仅演示安装相关阻断、失败、未知结果及现有模板审批权限，其他状态属于原组件的增量验收要求。

| 状态 | 反馈 | 动作与恢复 | 不适用说明 |
|---|---|---|---|
| 加载 | 载入说明，旧敏感内容不跨上下文显示 | 禁止重复提交；完成后恢复主内容 | 本地静态说明在真实产品无需请求 |
| 无权限 | 明确拒绝，说明联系管理员 | 返回可访问入口；不缓存正文、不显示零值 | 引导前由部署入口阻断 |
| 请求失败 | 保留输入/已授权局部内容，错误编号 | 重试当前读取；不自动重复写入 | 安装结果未知专用查询原操作 |
| 离线 | 持久提示，写动作禁用 | 保留当前输入；恢复网络查询写入结果 | 离线不允许包安装/发布/签署 |
| 会话过期 | 锁定正文及写动作 | 重新认证后核验身份/版本才恢复 | 不将敏感内容写入未加密本地存储 |
| 空态 | 机构未配置、无就诊、无结果三种文案 | 按角色设置/登记/清除筛选 | 纯说明屏、进度/结果等无列表的屏不设“空数据”按钮 |
| 预检阻断/失效 | 指出缺依赖、冲突或过期 | 修复输入并重新预检 | 不允许“仍然安装” |
| 安装失败已回滚 | 零配置残留说明和失败编号 | 重新预检、创建关联重试 | 未确认回滚不得这样显示 |
| 安装结果未知 | 不显示成功或失败结论 | 查询同一操作；记录页持续可达 | 关闭页面不是取消任务 |
| 模板草稿/发布条件未满足 | 下一责任角色与原因 | 原“审批发布”或原新版本修订 | 既有领域多阶段流程继续适用 |
| 未保存/版本冲突 | 草稿标识、保存时间及冲突提示 | 保留输入、比较后保存；离开确认 | 不用后台刷新偷偷更新提交版本 |
| 质控失效/读取失败 | 旧结论带失效标记，签署沿原门禁 | 保存当前版后重检；正文保存独立 | 不把规则检查错误表述为医学结论 |
| AI 无模型/无命中/候选过期 | 分别说明原因 | 手工继续、重新检索/生成 | 不使用样例候选作为失败回退 |

要求测试的异常组合：切换角色时晚到响应；安装后断网再返回；预检后升级当前配置；保存成功而质控失败；已采用候选后切换文书版本。覆盖以真实测试记录为准，不把本矩阵存在当作执行通过。
