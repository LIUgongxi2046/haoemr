# 现有设计系统复用规范 · v0.2

CREATED。用户已明确原架构和原风格不变；撤回 v0.1 自定义的壳层、欢迎页、页面级设计地图与视觉参数。

## 唯一来源

原壳层使用 ClinicalShell.vue 的 `.shell/.topbar/.sidebar/.main`，系统管理使用 `.admin-domain-layout/.admin-domain-nav/.admin-domain-content`，新增对话框采用 AdminActionDialog 的 DOM 和样式。原品牌使用 brand-config.ts 的默认资产；不以新插画替换医院 Logo 或 Eva。

样式逐字复制并按 web/src/main.ts 的现有顺序加载：styles.css → prototype.css → align-prototype.css → vue/vue-shell.css。文件及 SHA-256 见 existing-ui-source-manifest.json。生产实施直接引用原项目样式，不创建平行主题，不整体改写原样式。

## 纠正 v0.1

原浏览器原型在 1280 宽的实测主栏为 220px、系统管理二级栏 176px、主区边距 22px、标题 21px、主操作蓝色。v0.1 的 216px、24–26px 标题、绿色主操作和大幅首次设置欢迎插画不再采用。实际生产响应式值由现有后加载的 vue-shell.css 决定，不能把这些观察值变成全局重设。

## 页面与导航

主菜单 15 项及系统管理二级链接 13 项均与当前 ClinicalShell 源码相同。管理工作台保留指标、模块入口、待办、最近发布结构，仅添加初始化检查区。参数开关增页内“模块初始化”；通知任务增页内“配置安装记录”。详情、预检、确认、差异、进度、结果使用已有管理弹窗。

模板发布不新增审批流程：沿用原模板“创建人不能审批/审批发布”。能力定义、模块依赖与灰度仍由原能力包页负责，系统管理仅导航过去。

## 增量组件与状态

增量样式统一限定 `integration-preview-*`（原型评审专用）。禁止覆盖 :root、shell、sidebar、main、btn、card 等现有全局选择器。文本、间距、边框、状态色均引用现有变量；桌面紧凑密度保持原样。原型 DOM 对未涉及功能只提供原页面链接和保留说明，不重新设计功能页面。

对话框保持原标题/说明/关闭/主体层级；确认显示机构、包版本、影响条数和生成草稿的含义。失败回滚与结果未知分开；关闭不取消运行。医生端的空态、质控与辅助规则写进原页面增量需求，停止维护独立临床原型。

手机沿用原壳层的导航收缩和系统管理二级入口布局；新增区块响应式单列、表格明确容器滚动、触控动作不遮挡。可访问性与安全规则继续使用原组件约束；没有借设计交付修改全局按钮尺寸。
