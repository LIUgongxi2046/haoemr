# HaoEMR 六项需求全产品复测报告

## 结论

本轮以路由契约全部 194 个页面为固定分母，不以用户举例页面为修复边界。六项需求在本地 `dev-synthetic` 环境已完成实施和回归，本轮安全级别结果为 P0=0、P1=0、P2=0。

## 需求覆盖

1. AI医助小南同时支持中窗与右侧窗；右侧窗在桌面端挤压主工作区自适应变窄，移动端保持可用。
2. 通用菜单通过真实页面动作注入诊断、医嘱、检验、影像、危急值、会诊、随访、病程版本、病案资产、紧急访问、质量指标、药房、手术、输血、护理与交接班等复杂合成数据；60 个专科菜单全部有持久化记录。
3. 全路由检测模块间距、顶层重叠、文字截断与横向溢出；文书模板小按钮统一提高点击高度。
4. 急诊留观、病案资产等页面补齐真实数据与结构化空态；筛选无结果时保留说明和下一步动作。
5. 移除住院工作站和结果中心重复的局部 Tab；开发角色模拟收起为非业务默认信息。
6. 住院病程与文书支持任务创建、建稿、读取、修改、新版本、质控、分级审签和版本证据查看；直达编辑/质控页时自动选择当前患者最近文书，不再因缺少查询参数变成空白页。已签临床事实不提供无审计物理删除，用新版本、作废/撤销和审计证据实现安全 CRUD 语义。
