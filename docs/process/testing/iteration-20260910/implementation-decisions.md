## 接口与安装决策

- 保留原根路由及 15/13 导航；参数页内模块初始化、通知任务页内安装记录；结果跳回原模板输出。
- 首版容器为单个 UTF-8 JSON。拒绝 ZIP/二进制/可执行内容和未定义字段；10 MB、1–500 条目、每模板最多 100 个稳定字段。只生成固定结构模板 schema，不允许任意 SQL、JS 或自由 schema。
- 包版本为精确三段数字；依赖为精确版本；app_version 与运行版本匹配。预检绑定目标机构/院区、包哈希、模板快照、保留决策和 15 分钟有效期，安装前重新核验。
- 可信来源采用部署方审定文件 SHA-256 白名单；白名单证明该完整文件被部署方认可，与只显示自算哈希不同。默认无正式信任；仅 dev-synthetic 可识别内置结构样例，不能被生产模式沿用。
- 安装引入必要的预检、操作、条目来源记录，沿用租户范围、数据库约束、原模板命令和审计/Outbox。首个小包同步原子执行，操作先持久化，浏览器断线查询原操作。
- 重试 key 唯一性与成功包版本唯一性分别处理；成功只表示草稿导入。保留医院修改时不把医院内容标成新包原始内容。
- 进程中断恢复由记录锁和事务事实判断；不能凭前端超时伪造失败。恢复动作仅在没有活跃事务、超过约定时间且操作未终结时确认回滚。

正式内容、正式 OIDC/签名/存储和院方恢复指标尚未提供；本轮对合成隔离环境进行实现验收，不宣称生产可用。

## 联调发现后的定向修复

- 同一事务内多次调用原模板命令时，`now()` 固定为事务开始时间，已在隔离浏览器库观察到审计前驱分叉。只将原 DocumentTemplateService 和新增安装协调器的审计时间取值改为 `clock_timestamp()`；不修改历史审计。新增逐事件前驱断言验证批量写入结果。
- 原模板页安装来源查询纳入机构/身份范围；来源加载失败时不回退展示无关模板。UI 的新增移动端主要按钮受原 CSS 优先级影响不足 44px，按实测仅提升新增组件的触控最小高度。
- 首次管理员引导：复用 tenant/organization/facility/app_user/role_assignment 与原人员同步触发器，只解决首个认证主体尚不存在的循环依赖。默认关闭，仅 prod + non-web 命令可启用，原生产配置前置校验继续执行。请求精确绑定 OIDC issuer/sub 与预分配 tenant_id；并发锁和不可变审计控制重放，不创建密码或默认登录身份，不重置停用账号。原 HTTP 安全配置只增加 Servlet 环境条件，Web 模式行为保持原样。
- 任务允许修改补充：上述已定位根因涉及 DocumentTemplateService、原生产启动校验及 HTTP 安全配置；其余领域行为不扩大调整。
