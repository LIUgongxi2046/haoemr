## 0. 通用验收（每个任务适用）

1. Java 定向回归（隔离测试库）全绿；涉及契约的任务 `npm --prefix contracts run generate && --check` 一致。
2. 前端 Vitest + `npm run build` 通过；浏览器写入回归（`web/scripts/verify-*.mjs`）0 findings。
3. 页面不伪造：接不了的真实外部依赖必须 fail-closed 如实标注，禁止合成数据冒充已联调。
4. 同步更新对应验收报告与菜单文档，避免文档漂移。
5. 交接/自查已点名的 demo、静态壳、写死数据和主按钮未接线必须开发完整；不得以删除菜单、隐藏页面、禁用操作或仅修改文案作为验收。若同等真实能力已存在，必须复用并接通，不重建第二套系统。
