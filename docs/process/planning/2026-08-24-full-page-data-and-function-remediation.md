# HaoEMR 全页面数据与功能修复计划

## 范围与门禁

- 用户目标：品牌副标题修正；AI医助小南展示可选 Agent、介入时机与任务入口；遍历全部页面并补齐合成测试数据、核心交互和不规范 UI。
- 环境：本机 `dev-synthetic`，只使用脱敏合成数据；不向生产迁移数据，不改变生产身份与授权边界。
- 页面分母：路由契约中的 194 个页面；业务完整性门禁独立于“路由可访问”门禁。
- 非目标：本批次不部署、不迁移生产数据库、不自动执行高风险临床动作。

## 首批施工单

### FX-001 品牌副标题与色彩修正

- DoD：顶部显示“电子病历系统”，使用主题深蓝色；产品名仍为 HaoEMR，Logo 不变形。
- 验证：桌面与移动截图、顶部交互审计。

### FX-002 全局 AI Agent 目录与直接任务选择

- DoD：弹窗明确展示 Agent 总数、每个 Agent 的介入阶段、可执行任务与安全边界；用户可直接点击 Agent 任务执行，也可选择 Agent 后输入自定义任务。
- 安全：Agent 不自动写入临床事实；高风险动作仍需人工确认和后端门禁。
- 验证：弹窗键盘/按钮操作、选择状态、发送上下文中包含 Agent 标识。

### FX-003 / FX-004 门诊诊疗闭环

- DoD：默认合成门诊患者至少有诊断、处方/检查医嘱、检验结果和会诊记录；四个页面有统计、筛选、主要操作、空/错/加载状态和明确下一步。
- 数据：只由 `dev-synthetic` 导入器幂等注入，使用固定 UUID，可重复启动。
- 验证：API 数量断言、页面数据断言、至少一个非破坏性操作闭环。

### FX-005 全页面审计

- DoD：每个路由记录可达性、主标题、数据卡/表格/表单、可用按钮、空状态、控制台错误和失败响应；输出 P0/P1/P2 缺口清单。
- 说明：页面“能打开”不得冒充“功能完整”。

### FX-006 / FX-007 批量修复与回归

- DoD：P0/P1 缺口逐项有实现和证据；运行单元、类型、构建、194 路由双视口、按钮级和数据完整性审计。
- 回滚：源码按文件回退；合成数据只存在于开发数据库，可按固定 UUID 清理；无生产数据变更。
