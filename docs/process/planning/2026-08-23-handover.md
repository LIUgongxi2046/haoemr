## 2. 关键技术点（后续开发必读）

### 2.1 上下文租约作用域（三类，前端 API 客户端必须对齐）

| 作用域 | 端点示例 | 租约 + 头 |
|---|---|---|
| 患者级（encounter=null） | pharmacy/imaging/surgery/emergency-*/medical-record-assets/action-executions | `issueContextLease(patientId, null, p)` + `explicitContextHeaders(lease, patientId, null)` |

| 院区级（无患者） | shift-handovers/price-catalogs/waiting-queue/specialty-support/source-* | `issueContextLease(null, null, p)` + `wardHeaders(lease)` |

## 6. UI 对齐高保真原型的做法与踩坑（本轮新增，必读）

> 完整 10 条根因见 `DEVELOPMENT_PRINCIPLES.md` §六。这里只留「怎么做对」的操作清单与关键文件。

**对齐原型的正确姿势（别再猜）**：
1. 以**实际渲染**为准，不以源码猜测。用 Playwright `page.evaluate` dump `getComputedStyle` + `element.textContent` 到文本（模型读不了截图），据此对齐。
2. 视觉真相是 `prototype/app/styles.css`（已演进），不是 `tokens.json`。
3. 原型导航在 `prototype/app/coverage.js`（`coveragePages`，14 项 5 组）+ `specialties.js`（`specialty-center` 拼接），**不是** `app.js` 里那份旧 `pages`。

**本轮落地文件**：
- `web/src/prototype.css` = `prototype/app/styles.css` 原样拷贝（最后 import）。
- `web/src/align-prototype.css` = 生产 `.admin-*`/`.button`/`.content` → 原型 `.card`/`.table`/`.metric`/`.status`/`.btn`/`.main` 的类名映射。
- `web/src/vue/components/ClinicalShell.vue` = 改用原型类名（`.shell`/`.sidebar`/`.main`）+ 14 项侧栏 + center-nav 子导航。

**已修的历史 bug（勿重犯）**：
- `:root` 令牌自引用（`--nav:var(--nav)`）→ 颜色全失效。
- 双层 padding（`.main` + `.content` 各 22px）→ 内容双倍缩进。
- `.nav-item > span` 边框盒残留 → 图标/文字/计数都套白线框。
- CSS 注释含 `*/`（`.admin-*/`）→ lightningcss 报错。
- vue-tsc 内存不足假挂起 → 先释放内存或用 `vite build` 验证。
