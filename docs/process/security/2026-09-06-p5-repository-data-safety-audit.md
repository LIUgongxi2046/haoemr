- 状态：VERIFIED

- 修复记录：`scripts/security-scan.sh` 的 `sk-` 规则增加边界约束，消除了 `task-*` 字符串的误报；GitHub token 规则扩展到更多 token 前缀。
- 剩余风险：正则扫描无法证明短口令、未知格式 token 或经编码/拆分的秘密不存在；如果未来发现真实密钥，必须立即吊销并轮换，不能只删除当前文件。

## P5 退出条件

公开发行前至少完成：

1. 第二人复核当前 10 个文本候选文件，并确认所有样例均为不可关联真实个人的合成数据。
