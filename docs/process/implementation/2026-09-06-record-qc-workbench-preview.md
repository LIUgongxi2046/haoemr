# B1-SAFE 病历工作台内嵌质控预览

日期：2026-09-06。范围：原 19 项任务中的工作台入口增量，不代表全部任务完成。

## 行为与安全边界

- 原病历工作台每行增加「查看质控」，在当前页面弹窗读取真实治理证据及对应只读章节。
- 增加硬阻断/开放问题/暂无开放问题筛选，与原患者、文书状态和就诊类型筛选组合使用。无匹配时显示明确空态。
- 「暂无开放问题」不再以绿色通过状态呈现，明确它不等同于已检查通过。
- 预览沿用既有租约签发、文书 GET、governance GET 和生成的契约校验；没有新增后端 API 或数据库迁移。
- 租约针对所选行的患者/就诊签发，GET headers 使用该租约绑定的明确范围，不调用 `selectOutpatientContext`，不修改当前接诊患者。
- 文书、工作台快照和质控证据的文书 ID、版本及内容哈希不一致时拒绝混合展示。用户关闭并刷新工作台后重新选择。
- 院区、机构或用户变化时重新加载并清除旧展示；预览组件关闭即卸载、查询缓存 gcTime=0。
- 无运行质控、保存、签署或流转按钮；原编辑、保存、签署、抽查及其他页面代码未改动。文书预览仅为人工查看，不自动采纳 AI。
