# 项目文档导航

本目录只存放需要长期维护或用于研发追溯的文档，不放应用运行代码和生成型测试产物。

| 目录 | 分类 | 主要内容 |
|---|---|---|
| `product/` | 产品事实 | 战略、竞品与法规调研、PRD |
| `design/` | 设计交付 | HLD/LLD、原型规格、UI 设计系统、页面与状态设计 |
| `process/` | 研发过程 | 实施计划、交接、评审、测试报告、质量、安全与运维记录 |
| `development/` | 开发说明 | 工具链、环境和本机开发约束 |
| `database/` | 数据库说明 | Schema 参考与数据库文档 |
| `archive/` | 历史资料 | 已被当前计划替代、但仍需追溯的旧任务文档 |

## 阅读顺序

1. 根目录 `DEVELOPMENT_PRINCIPLES.md`。
2. `product/prd/2026-08-11-haoemr-v1.0-prd.md`。
3. `design/architecture/README.md` 与相关 HLD/LLD。
4. `process/planning/2026-08-24-remaining-development-backlog-v4.md`。
5. `process/testing/2026-08-24-s008-remaining-features-closeout.md`。

浏览器截图与审计 JSON 不在文档目录，统一位于根目录 `artifacts/`。
